# 범일 vs 문현 — 남구5 어디서 탈까

부산 BIMS(부산광역시 버스정보시스템) 실시간 도착 정보로 남구5가 범일역·문현역(집 방향)에 언제 오는지 30초마다 확인하고, 부전 하나로마트에서 출발했을 때 어디서 타야 집에 먼저 도착하는지 알려줍니다.

## 1. API 키 받기 (무료)
1. 공공데이터포털(data.go.kr)에서 **"부산광역시_부산버스정보시스템"**을 검색하고 활용신청합니다.
2. 마이페이지 → 활용신청 현황에서 **일반 인증키(Decoding)**를 복사합니다. 승인 후 키가 동작하기까지 1~2시간 걸릴 수 있어요.

## 2. 넷리파이 배포
- GitHub에 이 폴더를 올리고 Netlify에서 New site → 저장소 선택. 빌드 설정은 netlify.toml에 들어 있어요.
- Site configuration → Environment variables에 `BIMS_KEY` = 복사한 Decoding 키를 넣고 다시 배포합니다.
- (CLI 사용 시) `npm i -g netlify-cli` → `netlify deploy --prod`

## 3. 확인
- `https://사이트주소/api/bus` 를 열어 범일역·문현역 정류장 이름과 buses 목록이 나오면 정상입니다.
- 문제가 있으면 `/api/bus?debug` 결과를 보면 원본 응답을 확인할 수 있어요.
- 폰에서 사이트를 열고 "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다.

걸리는 시간(지하철, 환승, 도보 등)은 화면 아래 설정에서 바꿀 수 있고 폰에 저장됩니다.
